# 10^6 以下の素数表

[説明書の目次](../index.md) · [コード](../../../MathNumberTheory/primes_upto_1000000.txt) · [確認対象の公開版](https://github.com/yuki-4869/Algorithm/blob/933b86ab8c6dde6d09fbe6328e4778a780264ed3/MathNumberTheory/primes_upto_1000000.txt)

10^6以下の素数を昇順で列挙したデータです。

型エイリアス・マクロとコードの置き方は [共通設定](../common.md) を参照してください。

**記号**

P=素数の個数。先頭の説明行を除く{...}はvector等の初期化子として使えます。

**共通の前提**

- 整数列は78,498個で先頭2、末尾999983。ファイル先頭の「素数」は説明文字で、C++の式ではありません。

## この実装の注意点

これは関数やヘッダではなくテキストデータです。std::binary_searchはO(log P)、lower_boundもO(log P)、全素数の走査はO(P)。篩による生成結果と一致することを整理時に確認しています。

## 使用例

必要な定義を用意して、次の処理を `main` 内で実行します。`assert` で結果を確認しています。

```cpp
vector<ll> primes={2,3,5,7,11}; // 実際には元ファイルの{...}全体を貼ります。
assert(binary_search(primes.begin(),primes.end(),7));
```

## メモリ

データO(P)。

## 使用例の確認状況

GCC 13.3.0、`-std=c++23` とACLで、掲載例のコンパイル・実行および `assert` の成功を確認しました。 掲載例は先頭部分を示しています。検証では元ファイルの全78,498個を初期化子として使用しました。全素数表の一致は初回整理時に別途篩で確認しています。

元コードの未修正時の結果・検証条件は [C++23での確認結果](../validation.md) を参照してください。
