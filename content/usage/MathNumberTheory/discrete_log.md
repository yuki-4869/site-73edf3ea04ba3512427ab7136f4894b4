# 離散対数（非互いに素対応）

[説明書の目次](../index.md) · [コード](../../../MathNumberTheory/discrete_log.cpp)

整数a、bと正整数mに対し、

$$
a^x\equiv b\pmod m
$$

を満たす**最小の非負整数x**を求めます。存在しなければ-1を返します。
乗算を繰り返した余りが初めて目標値になる時刻や、mod累乗を逆向きに解く処理に使えます。
法は素数でなくてもよく、aとmが互いに素でない場合やb=0にも対応します。

既存の [mod累乗・逆元](mod_pow_inverse.md) が指数を与えて剰余を計算するのに対し、本関数は目標の剰余から指数を求めます。
型エイリアスと貼り付け方は [共通設定](../common.md) を参照してください。
基本テンプレート以外のinclude、ACL、他の個別ライブラリへの依存はありません。

## 型・前提

```cpp
using ll = long long;
using LL = __int128;
using pll = pair<ll, ll>;
```

- `1 <= m <= LLONG_MAX` とします。m=1も有効です。
- a・bはllの範囲全体、すなわちLLONG_MINからLLONG_MAXまで使えます。関数内で0以上m未満に正規化します。
- 指数は0を含みます。a=0でも $a^0=1$ と定義します。
- 解が複数ある場合も、返すのは最小の1つだけです。全解の列挙や、指数の周期の取得は行いません。
- 正のmでの積は128bit整数で計算するため、llの乗算によるオーバーフローを避けます。
- 必要な時間・メモリを確保できることが前提です。ll全域の法を受け取れますが、一般の $m\approx10^{18}$ を実用的な時間・領域で解けるという意味ではありません。

## 構築方法

実装をグローバルに置き、`discrete_log(a,b,m)` を呼び出します。
クラスの構築やbuildは不要で、呼ぶたびに独立して計算します。
前の呼び出しの配列は保持せず、入力値も変更しません。
複数クエリ間での前計算共有は行いません。

## discrete_log

```cpp
ll discrete_log(ll a, ll b, ll m);
```

引数aを底、bを目標の剰余、mを法として、上の合同式を満たす最小の非負整数xを返します。
指数xを0から順に全て試す代わりに、最大公約数による縮約とBaby-step Giant-step法（BSGS）で探索します。

解がなければ-1です。aとmが互いに素でないことだけを理由に-1を返すことはありません。
法の素数性判定や因数分解、逆元計算は必要ありません。

`m <= 0` ではNDEBUGでもメッセージなしで停止します。

### 特別な入力

以下のa・bは正規化後の値です。

| 入力 | 返り値 |
| --- | --- |
| m=1 | 常に0 |
| m>1、b=1 | 常に0 |
| m>1、a=0、b=0 | 1 |
| m>1、a=0、bが0でも1でもない | -1 |
| m>1、a=1、b!=1 | -1 |

これらは大きな法でも配列を確保せずO(1)時間・領域で処理します。
ほかの入力にも最大公約数の段階で終了するものがあります。

### 計算量・メモリ

元の法をM、最大公約数を取り除いた後の法をR、$W=\lceil\sqrt R\rceil$ とします。

- 全体の最悪計算量は $O(\sqrt M\log M)$ 時間・$O(\sqrt M)$ 追加領域です。M=1はO(1)です。
- 最大公約数による縮約は高々O(log M)回です。各回のEuclid法を含め、O(log² M)時間・O(1)領域で処理します。
- BSGS部分はO(W log W)時間・O(W)領域です。W<=1の部分はO(1)と読みます。
- 配列は重複を除く前にW組を確保します。異なる剰余が少なくても初期確保量は減りません。

一般的な64bit環境では、1組は2つのllで16バイトです。Rが $10^9$ 程度なら約3.2万組、$10^{12}$ 程度なら約100万組を使います。
Rが $10^{18}$ 程度だと約10億組になり、通常の競技プログラミング環境には大きすぎます。
法が大きいクエリを多数回呼ぶ場合も、各回の計算量の合計に注意してください。

ソートと二分探索を使うため、ハッシュ表や乱数に依存しない計算量です。
平方根の近似値は128bit整数の平方比較で補正し、指数の組み立ても128bitで行います。
有効な最小解は元の法M未満なので、返り値はllに収まります。

## 使用例

実装をグローバルに置き、以下をmain内などで実行します。

```cpp
assert(discrete_log(2,8,13)==3);   // 2^3 ≡ 8 (mod 13)
assert(discrete_log(2,4,8)==2);    // 非互いに素でも解を求める
assert(discrete_log(2,0,8)==3);    // 2^3 ≡ 0 (mod 8)
assert(discrete_log(2,3,8)==-1);   // 1,2,4,0,0,...に3はない
assert(discrete_log(4,4,5)==1);    // 指数1,3,5,...のうち最小を返す
assert(discrete_log(-2,-8,13)==3); // 負数も正規化する
assert(discrete_log(0,1,7)==0);    // 0^0=1の約束
assert(discrete_log(0,0,7)==1);
assert(discrete_log(0,2,7)==-1);
assert(discrete_log(123,456,1)==0);

ll a=3,b=5,m=7;
ll exponent=discrete_log(a,b,m);
assert(exponent==5);
```

入力 `T` に続けて `a b m` がT行ある場合は、各行で本関数を呼び、返り値をそのまま出力できます。
指数の加算や符号の反転をする必要はありません。

## アルゴリズム

### 最大公約数を取り除く

現在の問題を

$$
k a^y\equiv b\pmod m,\qquad x=y+t
$$

の形で持ちます。最初はk=1、t=0です。
各段階でb=kならy=0が最小なのでtを返します。

$g=\gcd(a,m)>1$ なら、y>=1では左辺がgで割り切れます。
bがgで割り切れなければ解はありません。割り切れる場合は、

$$
b\leftarrow b/g,\quad m\leftarrow m/g,\quad
k\leftarrow k(a/g)\bmod m,\quad t\leftarrow t+1
$$

として、残りの指数を1減らした問題にします。
gcd(a,m)=1になるまで繰り返すことで、以後はaもkも現在の法と互いに素になります。
縮約後にもy=0を確認するため、途中で成立する最小解を取りこぼしません。

### BSGSで残りの指数を探す

縮約後の法をRとし、$W=\lceil\sqrt R\rceil$ とします。
y=0はすでに確認したので、正の候補を

$$
y=iW-j,\qquad 1\le i\le W,\quad 0\le j<W
$$

と表します。この範囲で1以上W²以下の全ての整数を表せます。
合同式は、aが可逆であることから

$$
k a^{iW}\equiv b a^j\pmod R
$$

と同値です。右辺をjごとに列挙してソートし、左辺をiの昇順に進めて二分探索します。
同じ右辺が複数のjで現れた場合は、**最大のj**を残します。これにより、そのiでのyが最小になります。

iごとの候補範囲は `[1,W]`、`[W+1,2W]`、…の順なので、最初に見つかったものが全体でも最小です。
最後に縮約分のtを加えて返します。
法Rと互いに素な元の周期は高々Rであり、存在する最小の残り指数はR未満です。W²>=Rなので、この探索範囲で十分です。

## 確認結果

専用テスト `tests/discrete_log_test.cpp` で、法1から180までの全てのa・bを確認します。
別実装で累乗の剰余列を周期に入るまで全列挙し、各剰余の初出指数と比較するため、合同式を満たすことに加えて最小性と解なしの判定も検証します。
ランダムな合成数mod、負数、0、LLONG_MIN／LLONG_MAX、2冪・3冪、最大公約数を複数回除くケース、短周期で同じbaby-stepが重複するケースも確認します。
法が $10^{12}$ 規模のBSGSと、巨大な法でも縮約だけで終了するケースを含め、C++23の通常・NDEBUG・AddressSanitizer／UBSanで実行します。
