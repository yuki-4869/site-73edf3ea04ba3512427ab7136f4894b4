# 最小全域森（クラスカル法）

[説明書の目次](../index.md) · [コード](../../../Graph/kruskal.cpp)

重み付き無向グラフについて、各連結成分の頂点をつなぐ木のうち、重み合計が最小となるものを求めます。連結グラフでは最小全域木、連結でなければ各成分の最小全域木を合わせた最小全域森が得られます。道路の敷設費の最小化や、採用辺から木を作り直して木上の処理を行う問題に使えます。

## 型・前提

```cpp
using ll = long long;
using LL = __int128;
using tu = tuple<ll,ll,ll>;
using vl = vector<ll>;

struct KruskalResult {
    LL weight = 0;
    ll components = 0;
    vl edge_ids;
};
```

- 頂点数をN、辺数をMとします。`0 <= N <= INT_MAX`、`M <= LLONG_MAX` が必要です。
- `edges[id]={u,v,w}` は頂点uとvを結ぶ重みwの無向辺です。頂点番号と入力辺番号は0-indexedです。
- `0 <= u,v < N` が必要です。重みは負数や0を含むllの全範囲を取れます。多重辺は個別に扱い、自己ループは採用しません。
- 空グラフと孤立点を含むグラフにも対応します。N=0では辺リストも空とします。
- 頂点数、辺数、端点が範囲外なら、NDEBUGでもメッセージなしで停止します。必要なメモリを確保できることが前提です。

## 構築方法

実装を基本テンプレートの共通定義の後に置き、`kruskal(n,edges)` を呼び出します。呼び出しごとに独立に計算します。基本テンプレートの `<atcoder/all>` に含まれる `atcoder::dsu` を使います。ACLを個別に読み込むテンプレートでは、呼び出し側で `#include <atcoder/dsu>` を追加してください。

## kruskal

```cpp
KruskalResult kruskal(ll n,const vector<tu>& edges);
```

頂点数 `n` と入力順の辺リスト `edges` から、最小全域森を返します。入力を変更せず、結果は入力への参照を持ちません。重みが等しい辺は元の辺番号の小さい方から処理します。

**計算量**　$O(N+M\log(M+1))$ 時間、$O(N+M)$ 追加領域。N=M=0ではともに $O(1)$ です。辺の並べ替えが $O(M\log(M+1))$ 時間で、Union-Findの操作は各辺につき定数回です。

## KruskalResult::weight

`LL` 型の重み合計です。採用辺がなければ0です。合計がllの範囲を超えることがあるため、llへ変換して出力するときは範囲を確認してください。参照は $O(1)$ 時間です。

## KruskalResult::components

孤立点を含む入力グラフの連結成分数を `ll` で返します。N=0なら0、Nが正で `components==1` なら最小全域木が得られています。参照は $O(1)$ 時間です。

## KruskalResult::edge_ids

選ばれた辺の元の入力番号を採用順に持つ `vl` です。重みの昇順で、同じ重みでは辺番号の昇順です。要素数は `n-components` で、`edges[id]` から頂点と重みを取得できます。各要素の参照は $O(1)$、全走査は採用辺数に比例します。

## 使用例

```cpp
vector<tu> edges={{0,1,4},{0,1,-2},{1,2,3},{0,2,3},{3,3,-9}};
auto forest=kruskal(4,edges);

assert(forest.weight==1);
assert(forest.components==2);
assert((forest.edge_ids==vl{1,2}));

Graph tree(4);
for(ll id:forest.edge_ids){
    auto [u,v,w]=edges[id];
    tree[u].push_back({v,w});
    tree[v].push_back({u,w});
}
```

頂点0・1・2を重み−2と3の辺でつなぎ、頂点3は孤立点として残ります。重み3の候補のうち、先に入力した辺が採用されます。

## アルゴリズム

各頂点が別々の成分に属する状態から始めます。辺を重み順に見て、両端点が異なる成分に属しているときだけ採用し、Union-Findで両成分を併合します。採用済みの辺で作った成分とその外側を結ぶ辺のうち、次に採用する辺は最も軽いものの1つです。カット性により、その辺を採用しても最適な森を完成できます。全辺を処理すると、元のグラフで連結な頂点は同じ成分にまとまります。

## 検証

小規模グラフでは辺集合を全列挙し、連結性を保つ森の最小重みと照合しました。負重み、同じ重みの辺、多重辺、自己ループ、空グラフ、孤立点、llの範囲を超える合計を確認しました。
