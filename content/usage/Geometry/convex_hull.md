# 凸包（整数座標）

[説明書の目次](../index.md) · [コード](../../../Geometry/convex_hull.cpp)

平面上の点をすべて含む最小の凸多角形を求めます。点集合の外周の抽出、面積・周長の計算、最遠点対を求める回転キャリパー法の前処理などに使えます。
既存の偏角ソートが原点から見た方向の整列を行うのに対し、この関数は内部の点を除き、凸包の境界を反時計回りに返します。

整数の外積を128 bitで計算するため、浮動小数点の誤差判定はありません。
型エイリアスと貼り付け方は [共通設定](../common.md) を参照してください。

## 型・前提

```cpp
using ll = long long;
using LL = __int128;
using pll = pair<ll,ll>;
```

基本テンプレートの上記の型を使います。追加のinclude・ACLへの依存はありません。実装はグローバルに貼り付けます。

- 点は `(x,y)` で表し、各座標は整数、絶対値が $10^{18}$ 以下です。
- 入力点数をN、重複を除いた点数をMとします。必要なメモリを確保できることを前提とします。
- 添字は0-indexedです。元の入力の添字を保持するAPIではなく、座標列を返します。
- 座標差は128 bitへ変換してから取り、外積の絶対値の上界 $8\times10^{36}$ は符号付き128 bitに収まります。
- 座標範囲外はメッセージなしで停止します。NDEBUGでも検査は有効です。浮動小数点の点列は受け取りません。

## convex_hull

```cpp
vector<pll> convex_hull(vector<pll> points, bool keep_collinear = false);
```

### 引数

- `points`：凸包を求める点列。順序は任意で、同じ座標を複数回含んで構いません。
- `keep_collinear`：falseなら凸包の頂点のみ、trueなら凸包の辺上にある入力点もすべて残します。

構築用クラスやbuild操作は不要で、点列を渡して直接構築します。値渡しのため、呼び出し元の点列の内容・順序は変わりません。`std::move(points)` で渡した場合は、その入力列を以後利用しないでください。

### 返り値・順序

重複座標を取り除いた凸包の座標列を返します。入力にない点は追加しません。
全点が一直線ではない場合、辞書順最小の点から反時計回りです。辞書順はxが小さい順、xが同じならyが小さい順です。
末尾へ始点をもう一度追加しないため、最後の辺は `hull.back()` から `hull[0]` へ結びます。

| 入力 | false | true |
| --- | --- | --- |
| 空 | 空のvector | 空のvector |
| 同じ座標のみ | その座標1個 | その座標1個 |
| 異なる2点 | 辞書順の2点 | 辞書順の2点 |
| 全点が一直線 | 辞書順の両端2点 | 重複を除いた全点を辞書順 |
| それ以外 | 辺の途中の点を含まない頂点列 | 辺の途中も含めた境界点列 |

一直線の場合に返す列は往復させず、各点が1回だけ現れます。trueの返り値では隣り合う辺が一直線になるため、厳密な凸性を前提とする後続アルゴリズムにはfalseを使用してください。

### 計算量

$O(1+N\log(N+1))$ 時間、入力の値渡しコピー・作業領域・返り値を含め $O(N+1)$ 領域です。辞書順ソートが支配的で、整列後の走査はO(M)です。

## 使用例

実装をグローバルに貼り付け、以下をmain内などで実行します。

```cpp
vector<pll> points={{0,0},{1,0},{2,0},{2,2},{0,2},{1,1},{0,0}};
auto original=points;
auto hull=convex_hull(points);
assert((hull==vector<pll>{{0,0},{2,0},{2,2},{0,2}}));
auto boundary=convex_hull(points,true);
assert((boundary==vector<pll>{{0,0},{1,0},{2,0},{2,2},{0,2}}));
assert(points==original);
assert(convex_hull({}).empty());
assert((convex_hull({{3,4},{3,4}})==vector<pll>{{3,4}}));
assert((convex_hull({{2,2},{0,0},{1,1}})==vector<pll>{{0,0},{2,2}}));
assert((convex_hull({{2,2},{0,0},{1,1}},true)==vector<pll>{{0,0},{1,1},{2,2}}));

LL area2=0;
for(size_t i=0;i<hull.size();++i){
    auto [x,y]=hull[i];
    auto [nx,ny]=hull[(i+1)%hull.size()];
    area2+=LL(x)*ny-LL(y)*nx;
}
assert(area2==8); // 面積はarea2/2。空・1点・一直線なら0
```

面積計算も128 bitを使ってください。上記は小さな座標の使用例です。大きな座標で多数の頂点の面積を求める場合は、`hull[0]` を基準に三角形へ分割し、非負の外積を加算すれば、途中の和も凸包全体の2倍面積以下に抑えられます。128 bit整数は基本のストリーム出力には直接渡せません。

## アルゴリズム

Andrewの単調鎖法を使用します。点を辞書順にソートして重複を取り除き、左から右へ下側の境界、右から左へ上側の境界を構築します。
追加点と直前の2点が右折を作る間、直前の点を除きます。falseでは一直線の場合も除くことで、辺の途中の点を残さないようにします。
trueでは一直線の点を保持しますが、全点が一直線の場合には上下の境界が重なるため、先に検出して辞書順の列を返します。

各点は各鎖へ1回追加され、高々1回削除されるので、ソート後の計算量は線形です。
上下の鎖の端点の重複を除いて連結すると、辞書順最小から始まる反時計回りの境界が得られます。

## 検証

専用テスト `tests/convex_hull_test.cpp` で、3×3格子の全512部分集合を独立した支持直線の全探索と比較します。
境界点を残す両設定、重複点、順序の入れ替え、空・1点・一直線、座標の絶対値 $10^{18}$ を検証します。
ランダム点集合と50万点のケース、C++23・NDEBUG・サニタイザでも確認します。
