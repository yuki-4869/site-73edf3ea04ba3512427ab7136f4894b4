# 長方形の和集合面積

[説明書の目次](../index.md) · [コード](../../../Geometry/rectangle_union_area.cpp)

座標軸に平行な長方形を重ねたとき、少なくとも1枚に覆われる領域の面積を求めます。複数枚が重なる部分も1回だけ数えます。広い座標平面で、長方形として与えられた塗りつぶし領域や障害物の占有面積を集計するときに使えます。

## 型・前提

```cpp
using ll = long long;
using LL = __int128;
using vl = vector<ll>;
using tu4 = tuple<ll,ll,ll,ll>;
```

- 各長方形は `tu4{left,down,right,up}` で、領域は `[left,right) × [down,up)` です。各端点はllの全範囲を取れます。
- `left <= right` かつ `down <= up` が必要です。幅または高さが0の長方形は読み飛ばします。
- 入力数NはINT_MAX以下で、作業領域を確保できることが前提です。入力順は任意で、重複も許されます。
- 左右・上下が逆の場合、またはNがINT_MAXを超える場合は、NDEBUGでもメッセージを出さずに停止します。

## 構築方法

[共通設定](../common.md) に従い、実装を基本テンプレートの共通定義の後に貼り付けます。追加includeやACLの機能は不要です。クラスの構築や前処理は不要で、呼び出すたびにその入力をまとめて処理します。

## rectangle_union_area

```cpp
unsigned __int128 rectangle_union_area(const vector<tu4>& rectangles);
```

引数 `rectangles` の和集合面積を符号なし128 bit整数で返します。空入力や、すべての長方形の面積が0のときは0を返します。辺や頂点だけの接触は面積に影響しません。関数は入力を変更しません。

llが64 bitの環境では、座標差が最大 $2^{64}-1$ です。引き算の前に `LL` に拡張し、積と和は符号なし128 bit整数で計算します。結果はすべての長方形を含む外接長方形の面積以下なので、最大でも $(2^{64}-1)^2$ です。

**計算量**　O(N log N)時間、O(N)追加領域。Nが0または1のときはいずれもO(1)です。

## 使用例

```cpp
vector<tu4> rectangles={{0,0,3,2},{2,1,5,4},{0,0,3,2},{1,-2,1,5}};
auto area=rectangle_union_area(rectangles);
assert(area==14);
cout<<static_cast<ll>(area)<<'\n';
```

面積6と9の長方形が面積1だけ重なるので、答えは14です。重複した長方形と幅0の長方形を足しても答えは変わりません。

上の例では答えがllに収まるため変換して出力しています。llの範囲を超える場合は次のように十進表記にできます。

```cpp
string digits;
do{
    digits.push_back(char('0'+area%10));
    area/=10;
}while(area>0);
reverse(digits.begin(),digits.end());
cout<<digits<<'\n';
```

## アルゴリズム

各長方形の左端でy区間を追加し、右端で同じ区間を削除するイベントを作り、x座標順に処理します。隣り合うイベントのx座標の間では、覆われているy区間が一定です。その区間の幅と、覆われているy座標の長さの積を足します。同じx座標にイベントが複数あるときは、間の幅が0なので、処理順によって面積は変わりません。

長方形の上下端を座標圧縮し、セグメント木の葉に隣り合うy座標間の区間を割り当てます。長さの計算には圧縮前の座標を使います。各ノードでは、自分の担当区間を丸ごと覆うように割り当てられた区間の本数と、自分および子孫への割り当てで覆われている長さを管理します。本数が正ならノードの区間全体が覆われ、本数が0なら左右の子の長さの和を取ります。葉で本数が0のときは長さ0です。したがって根の長さは現在覆われているy区間の和集合の長さです。

## 検証

小さい整数座標では、単位マスを1つずつ調べて得た面積と比較しました。空入力、重複、入れ子、接触、退化長方形、同じx座標での追加と削除、llの両極値を含む入力も確認しました。
