# 接尾辞オートマトン（Suffix Automaton）

[説明書の目次](../index.md) · [コード](../../../String/suffix_automaton.cpp)

固定した文字列を前処理し、その中で任意のパターンが何回現れるかを求めます。異なる部分文字列の個数や、別の文字列との最長共通部分文字列の長さも取得できます。辞書や長いテキストを固定し、多数のパターンを後から照会する場面に使えます。

ここでの部分文字列は連続した区間です。出現位置は0-indexedで数え、同じパターンが重なって出現する場合も、開始位置ごとに数えます。比較には文字ごとの遷移を使うため、ハッシュ衝突は発生しません。

## 型・前提

```cpp
using ll = long long;
```

- 構築文字列 `s`、検索パターン `pattern`、比較文字列 `t` は、いずれも英小文字 `a..z` とします。空文字列も使用できます。
- $N=|s|$ は `INT_MAX/2` 以下とし、作業領域を確保できることを前提とします。各状態には26要素の `int` 遷移表があり、$N>0$ なら最大 $2N$ 状態分を確保します。
- 構築時の長さ超過や不正な文字の入力では、NDEBUGでもメッセージを出さずに停止します。検索中に一致しないと分かった場合も、残りの文字を検査します。
- 構築時に入力を変更せず、構築後に入力への参照を保持しません。

## 構築方法

```cpp
explicit SuffixAutomaton(const string& s);
```

実装を基本テンプレートの共通定義の後、mainの外に置き、`SuffixAutomaton sam(s);` とします。構築時に `s` 全体の遷移と出現回数を計算します。構築後の問い合わせはすべて `const` です。型定義と配置は [共通設定](../common.md) に従います。追加includeやACLの機能は不要です。

**計算量**　$O(N)$ 時間・領域。空文字列ではともに $O(1)$ です。

## count

```cpp
ll sam.count(const string& pattern) const;
```

`s` の中で `pattern` が現れる回数を返します。たとえば `ababa` の中の `aba` は、添字0と2から始まるので2回です。見つからなければ0を返します。空文字列は、先頭、各文字の間、末尾のすべての境界に現れるので $N+1$ 回です。

**計算量**　$O(|pattern|)$ 時間・$O(1)$ 追加領域。空文字列では $O(1)$ 時間です。

## distinct_count

```cpp
ll sam.distinct_count() const;
```

`s` に含まれる異なる非空部分文字列の個数を返します。同じ内容は出現位置が複数あっても1つと数えます。`s` が空なら0です。結果は最大 $N(N+1)/2$ なので `ll` で保持します。

**計算量**　$O(1)$ 時間・追加領域。

## longest_common_substring_length

```cpp
ll sam.longest_common_substring_length(const string& t) const;
```

`s` と `t` の両方に含まれる連続部分文字列の最大長を返します。共通する文字がなければ0です。どちらかが空の場合も0を返します。

**計算量**　$O(|t|)$ 時間・$O(1)$ 追加領域。`t` が空の場合は $O(1)$ 時間です。

## 使用例

```cpp
SuffixAutomaton sam("ababa");
assert(sam.count("aba")==2);
assert(sam.count("ac")==0);
assert(sam.count("")==6);
assert(sam.distinct_count()==9);
assert(sam.longest_common_substring_length("zzbabb")==3);
```

`ababa` の異なる非空部分文字列は、長さ1から順に2、2、2、2、1種類あります。`zzbabb` との最長共通部分文字列は `bab` です。

## アルゴリズム

部分文字列の出現が終わる位置の集合を `endpos` と呼びます。根から文字ごとに遷移すると部分文字列を検索でき、同じ `endpos` を持つ部分文字列は同じ状態に着きます。新しい文字を足したとき、従来は同じ状態だった部分文字列の `endpos` を分ける必要があれば、状態を複製して遷移を付け替えます。

各接頭辞の終端状態に1を置き、各状態が表す最大長の降順で接尾辞リンクの先へ足します。複製しただけの状態の初期値は0です。これで、各状態の `endpos` の大きさを出現回数として利用できます。

状態 $v$ が表す部分文字列の長さは、接尾辞リンク先の最大長を $L_{link(v)}$、自身の最大長を $L_v$ として、$L_{link(v)}+1$ から $L_v$ までです。各長さにつき文字列が1つ対応するので、根以外の状態について $L_v-L_{link(v)}$ を足すと、異なる非空部分文字列の個数になります。

最長共通部分文字列の問い合わせでは、`t` を左から読んで、各位置で終わる一致の最大長を追跡します。次の文字へ遷移できなければ、接尾辞リンクをたどって短い候補に移ります。リンクをたどるたびに長さが減り、1文字読むたびに高々1増えるので、リンクをたどる合計回数は $O(|t|)$ です。

## 検証

小規模の二値文字列で、出現回数と異なる部分文字列数を列挙と比較し、最長共通部分文字列長を二次元DPと照合しました。空文字列、重複出現、不正な文字、20万文字の入力、異なる部分文字列数が32 bitを超える例も確認しました。
