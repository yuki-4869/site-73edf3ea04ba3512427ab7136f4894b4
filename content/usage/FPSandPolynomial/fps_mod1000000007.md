# 形式的冪級数（1000000007）

[コード](../../../FPSandPolynomial/fps_mod1000000007.cpp) · [FPS・多項式の一覧](../index.md#category-12)

係数列を多項式または形式的冪級数として扱います。係数の添字は0-indexedで、`f[i]` は $X^i$ の係数です。

## 準備・型

基本テンプレートにこのファイルを貼り付けます。`code`・`codet` はACLを含みます。`codecf` では `#include <atcoder/convolution>` を有効にしてください。
`ll` と標準ライブラリの型・関数を利用します。本体にはincludeを入れていません。

```cpp
using Mint=atcoder::modint1000000007;
using vMint=vector<Mint>;
```

法は **1000000007固定**です。998244353版と1000000007版は同名の `FPS` を定義するため、一方を選びます。
追加の [Bostan–Mori](bostan_mori.md)・[多点評価／補間](multipoint.md)・[総積](polynomial_product.md)・[組合せ数列](combinatorial_fps.md) は、選んだFPSの後に貼ると同じ法で動作します。

以下、`N=f.size()`、二つの多項式の項数をA・B、乗算の上界を $M(n)=O(n \log n)$ とします。法を固定した体演算で数えます。スカラー逆元1回には $O(\log p)$ が加わります。

## 係数列・項数・次数の読み方

`FPS f={5,3,2}` は $f(X)=5+3X+2X^2$ を表します。**定数項から低次の順**に並べ、`f[0]=5`、`f[1]=3`、`f[2]=2` です。これは値の列 $f(0),f(1),f(2)$ とは異なります。
`f.size()` は配列の項数です。この例の項数は3、次数は2です。末尾に0がある場合は項数から次数を決められません。

| 指定 | 意味 | 対応する呼び出し |
| --- | --- | --- |
| $X^0$ から $X^d$ まで求めたい | 必要な項数はd+1 | `f.inv(d+1)` など |
| `n` 項だけ求めたい | 次数0以上n未満の係数を保持する | `f.inv(n)`、`f.log(n)`、`f.exp(n)`、`f.pow(k,n)`、`f.sqrt(n)` |
| $X^d$ の係数を取りたい | 十分な長さを確保して添字dを見る | `h[d]`（`d<h.size()` が必要） |
| 1点での値を知りたい | 多項式に数を代入する | `f.eval(x)` |
| 多くの点での値を知りたい | 係数列から値の列に変換する | [多点評価](multipoint.md) の `multipoint_eval(f,x)` |

「mod $X^n$」は次数n以上を捨てる意味です。係数を法pで割った余りにする操作とは別で、例えば `f.inv(4)` は逆数の次数0,1,2,3の4係数を返します。
有限の配列として保持した `f` の範囲外は0として演算します。無限級数の先頭だけを保持している場合、`f.eval(x)` は保持した有限多項式に代入した値です。

## 構築・係数操作

`FPS` はvectorを継承します。`FPS()`、`FPS(n)`、`FPS(n,c)`、`FPS{a,b,...}`、`FPS(first,last)` を使えます。係数配列からの `FPS(v)` はコピー、`FPS(move(v))` は移動です。
構築は項数に比例し、空の構築・vectorからの移動はO(1)です。`size/resize`、`[]`、`begin/end`、`push_back`、`clear` 等も通常のvectorと同じです。

| API | 返り値・操作 | 計算量 |
| --- | --- | --- |
| `f.pre(n)` | 存在する先頭min(n,N)項を返す。0埋めしない | O(min(n,N)) |
| `f.rev()` | 係数順を反転したFPS | O(N) |
| `f.shrink()` | 末尾の0を取り除き、FPS&を返す | O(N) |
| `f.diff()` | 微分したFPS。定数・空は空 | O(N) |
| `f.integral()` | 積分定数0の積分。空は{0} | O(N) |
| `f.eval(x)` | Horner法で求めたMint型のf(x) | O(N) |

`pre` のnは非負です。積分ではN<p、Taylor shiftでは実際の次数<pが必要です。空配列も零多項式を表します。通常の加減乗算は末尾の0を自動では削除しません。

### 引数の意味

| 引数・呼び出し | 渡す値 | 返り値との対応 |
| --- | --- | --- |
| `FPS(n)` | 非負の項数n | n項の0を持つ係数列 |
| `FPS(n,c)` | 項数nと係数c | 全係数がcのn項の列。定数多項式cは `FPS{c}` |
| `FPS(v)` | `vector<Mint>` の係数列 | vの係数をコピーしたFPS |
| `FPS(first,last)` | 係数範囲の先頭・末尾イテレータ | 半開区間 `[first,last)` のコピー |
| `f.pre(n)` | 残したい先頭の項数n | 最大n項。短い場合に0を足さない |
| `f.eval(x)` | 代入する1個の `Mint` 型の値 | スカラー $f(x)$。係数列を返す関数ではない |

引数のない `rev()` は配列全体を反転し、`diff()` は微分、`integral()` は積分定数0の積分を返します。これらは元の `f` を変更しません。`shrink()` は元の `f` の末尾0を削除します。

## 演算子

| API | 返り値・操作 | 計算量 |
| --- | --- | --- |
| `f+g`, `f-g` | 係数の和・差。項数はmax(A,B) | O(max(A,B)) |
| `-f` | 全係数の符号を反転 | O(N) |
| `f*g` | 畳み込み。片方が空なら空、それ以外はA+B-1項 | O(M(A+B)) |
| `f/g`, `f%g` | 多項式の商・余り | O(M(A+B)) |
| `f+c`, `c+f`, `f-c`, `c-f` | 定数項との加減算 | O(N) |
| `f*c`, `c*f`, `f/c` | Mint型のスカラーとの乗除算 | O(N) |
| `f+=g`, `f-=g` | 自己更新してFPS&を返す | O(max(A,B)) |
| `f*=g`, `f/=g`, `f%=g` | 自己更新してFPS&を返す | O(M(A+B)) |
| `f+=c`, `f-=c` | 定数項を自己更新してFPS&を返す | O(1) |
| `f*=c`, `f/=c` | スカラーで自己更新してFPS&を返す | O(N) |
| `f<<k`, `f<<=k` | 低次に0をk項挿入してX^k倍 | O(N+k) |
| `f>>k`, `f>>=k` | 低次k項を削除。k>=Nなら空 | O(N) |

シフト量kは非負です。代入付き演算はFPS&、それ以外はFPSを返します。スカラーの除数は非零です。
空配列の左シフトはk項の零列になります。スカラー加減算は空なら1項に拡張します。

### 演算子の引数

`f`・`g` は係数列、`c` は1個の係数です。`f+c` は**定数項だけ**にcを足し、`f*c` は全係数をc倍します。`f*g` は係数ごとの積ではなく多項式積で、結果の係数は $h_i=\sum_{j=0}^i f_jg_{i-j}$ です。
シフトの `k` は非負整数で、`f<<k` は $X^k f(X)$、`f>>k` は低次k項を捨てて残りの次数をk下げた係数列です。右シフトで捨てた項は戻りません。

## 冪級数演算

```cpp
FPS inv(ll n) const;
FPS log(ll n) const;
FPS exp(ll n) const;
FPS pow(ll k,ll n) const;
FPS sqrt(ll n) const;
static pair<bool,Mint> mod_sqrt(Mint a);
```

| API | 返り値・前提 | 計算量 |
| --- | --- | --- |
| `f.inv(n)` | 1/f mod X^n。n>0ならf[0]!=0 | O(M(n)) |
| `f.log(n)` | log(f) mod X^n。n>0ならf[0]=1 | O(M(n)) |
| `f.exp(n)` | exp(f) mod X^n。n>0ならf[0]=0。空も可 | O(M(n)) |
| `f.pow(k,n)` | f^k mod X^n。kは非負ll | O(M(n)+log k) |
| `f.sqrt(n)` | 平方根mod X^nを一つ返す。不存在なら空 | O(M(n)+log p+v2(p-1)^2) |
| `FPS::mod_sqrt(a)` | 平方根があれば{true,r}、なければ{false,0} | O(log p+v2(p-1)^2) |

`n` は返す**項数**で、区間[0,n)を扱います。0<=n<=pに加え、次節の中間NTT長の制約を満たしてください。
n=0なら空、平方根が存在すればn項です。pow(0,n)は入力が零でも定数1をn項に拡張した列です。
sqrtでは、先頭非零項の次数が奇数、またはその係数が非平方剰余なら解がありません。mod X^nで零ならn項の零列を返します。
先頭非零係数の平方根は整数表現で小さい方を選びます。高次の自由な係数は0で補います。
v2(t)はtを割る2の指数です。負の指数は扱いません。入力は変更しません。

### n・k・aの意味

| 引数 | 意味 | 具体例 |
| --- | --- | --- |
| `n` | 出力する項数。最大次数を指定する値ではない | `inv(4)` は $X^3$ までの4項 |
| `k` | `pow(k,n)` の非負整数の指数 | `pow(3,5)` は3乗を $X^4$ まで求める |
| `a` | `mod_sqrt(a)` で平方根を求める1個の `Mint` 型の値 | `mod_sqrt(4)` は `{true,2}` |

`inv(n)` は積が1になる冪級数を返します。例えば $1/(1-X)=1+X+X^2+\cdots$ なので `FPS{1,-1}.inv(4)` は `{1,1,1,1}` です。
`log(n)` と `exp(n)` は、それぞれ定数項が1の級数の形式的対数、定数項が0の級数の形式的指数です。実数の近似計算ではなく、法p上で係数を計算します。例えば $\log(1+X)=X-X^2/2+X^3/3-\cdots$、$\exp(X)=1+X+X^2/2!+X^3/3!+\cdots$ です。分数は法上の逆元を使います。
`sqrt(n)` は $h(X)^2\equiv f(X)\pmod{X^n}$ を満たす係数列を返します。`n>0` で空が返れば平方根は存在しません。平方根が零の場合はn項の0が返るため、空との区別ができます。

## 多項式除算・Taylor shift

```cpp
pair<FPS,FPS> divmod(FPS g) const;
FPS taylor_shift(Mint c) const;
```

| 引数 | 意味 | 戻り値 |
| --- | --- | --- |
| `g` | 割る側の非零多項式。係数を低次から並べる | `divmod(g)` は商と余りの組 `{q,r}` |
| `c` | 変数Xに加える1個の値 | `taylor_shift(c)` は $f(X+c)$ の係数列 |

`divmod` は $f=qg+r$、$\deg r<\deg g$ を満たす{q,r}を返します。除数gは非零です。
商・余りの末尾0は除去し、零は空配列にします。計算量はO(M(A+B))で、小さい商・除数は筆算します。
`f/g` は冪級数の逆数との積ではありません。冪級数として割るなら `(f*g.inv(n)).pre(n)` を使います。

`taylor_shift(c)` はf(X+c)を**元と同じ項数**で返します。計算量はO(M(N))です。末尾0を含む場合は実際の次数分だけ計算します。

例えば `FPS{5,3,2}.taylor_shift(1)` は $f(X+1)=10+7X+2X^2$ の係数 `{10,7,2}` を返します。$f(X-c)$ が欲しければ `taylor_shift(-c)` とします。`f+c` の定数項への加算とは異なる操作です。

## convolution_1e9p7

```cpp
vMint convolution_1e9p7(const vMint& a,const vMint& b);
```

`a` と `b` はそれぞれ低次から並べた係数列（`vMint`）です。返り値 `c` の添字iには $\sum_{j+k=i}a_jb_k$ が入り、例えば `{1,2}` と `{3,4}` の畳み込みは `{3,10,8}` です。`FPS` 同士なら `f*g` でも同じ計算になります。

1000000007での畳み込みを返します。片方が空なら空、そうでなければA+B-1項です。計算量はO(M(A+B))、入力を変更しません。
長い積は167772161・469762049・754974721でNTTを行い、CRTで復元します。
NTT長が2^24以下なら、整数係数の上界は2^23(p-1)^2で、3素数の積より小さく、整数係数の復元は一意です。
998244353版よりNTTの回数とメモリの定数倍が増えます。

## 制約・キャッシュ

各中間畳み込みでNTTを使う場合、両入力の項数の和-1は **2^24以下**です。最終結果をpre(n)で切る場合も、切る前の中間積に適用されます。
短い方が60項以下の積は直接計算し、このNTT長制限を受けません。直接計算の時間はO(AB)です。
キャッシュを除く基本演算の作業領域はO(N)またはO(n)、積はO(A+B)です。

整数逆元・階乗・逆階乗は共有してキャッシュします。最大使用サイズまで合計O(N)の拡張時間とO(N)の常駐メモリを使います。
小さい多項式・空・定数は専用処理します。log・pow・sqrtは必要な接頭辞のみを利用します。
引数・長さの前提違反はNDEBUG時にも標準出力・標準エラーを出さず停止します。vectorの添字などは通常のvectorと同じく呼び出し側で管理してください。

## 使用例

```cpp
FPS f={1,2,3},g={1,1};
FPS product=f*g;
assert((product==FPS{1,3,5,3}));
FPS inverse=f.inv(6);
assert(((f*inverse).pre(6)==FPS{1,0,0,0,0,0}));
assert(f.log(6).exp(6)==FPS({1,2,3,0,0,0}));
FPS root=FPS{1,2,1}.sqrt(6);
assert(((root*root).pre(6)==FPS{1,2,1,0,0,0}));
auto [quotient,remainder]=f.divmod(g);
assert(quotient*g+remainder==f);
FPS shifted=f.taylor_shift(5);
assert(shifted.eval(3)==f.eval(8));
FPS large_power=f.pow(1000000000000LL,20);
assert((FPS{1,-1}.inv(4)==FPS{1,1,1,1}));
assert((FPS{1,1}.pow(3,5)==FPS{1,3,3,1,0}));
assert((FPS{5,3,2}.taylor_shift(1)==FPS{10,7,2}));
assert(FPS({5,3,2}).eval(2)==Mint(19));
assert((FPS{1,2}.pre(4)==FPS{1,2})); // preは0埋めしない
FPS padded=FPS{1,2}.pre(4);
padded.resize(4);                       // 4項が必要なら明示的に0埋め
assert((padded==FPS{1,2,0,0}));
```
